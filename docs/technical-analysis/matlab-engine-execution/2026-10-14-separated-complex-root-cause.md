# 分排涡扇复数序列化失败：现场诊断报告

## 结论

失败任务 `7a02bbd350d14cb9a1f9552403299482` 是单轴分排涡扇。
首次复数在设计点返回的 `DP.THRUST_REF` 中产生，早于任何工况扫描或绘图。
原项目和平台在同一输入下得到相同结果；227对现场比较未发现参数传递、
装配、数组形状或扫描状态差异。因此本次没有修改热力公式或求解设置。

零目标组合 `THRUST=0、WA=0、PWG=0` 使设计求解得到近零负空气流量。
等效喷速公式对负数开平方，生成复数，随后被保留到DP、扫描状态和MISSION。
MATLAB能保留该复数，但当前`jsonencode`不能编码它。

这次故障不能归因为轴数或构型复杂度；其他任务如产生复数，仍需使用其自己的输入和现场定位。

## 首次异常及表达式重放

零目标设计点现场：

| 字段 | 原项目与平台一致的值 |
|---|---:|
| DP.WA | -2.1607028237671951e-11 kg/s |
| DP.PW_REF | 5.0401619404220779e-11 kW |
| DP.THRUST | 0 kN |
| DP.PWG | -7.6516567848172151e-10 kW |
| DP.THRUST_REF | 1.2964216942603171e-12 - 7.05229904381539e-13 i |
| fsolve exitflag | 1 |
| 残差无穷范数 | 7.7345441162890438e-10 |

`DESIGN.m`第376—378行：

```matlab
V_EXT_cor=(2*(1000*PW_REF/WA+0.5*V^2))^0.5;
THRUST_REF=WA*(V_EXT_cor-V)/1000;
DP.THRUST_REF=THRUST_REF;
```

保存的求解变量重放得到：

```text
WA = -2.1607028237671951e-11
V = 60
PW_REF = 5.0401619404220779e-11
2*(1000*PW_REF/WA + 0.5*V^2) = -1065.2986102313989
```

重放的各气路组件返回状态没有复数；复数首次出现在上述等效喷速/等效推力计算中。
虚部很小源于乘上了接近零的WA，不能说明负平方根只是可忽略的舍入误差。
设计点虽然数值残差很小并返回正exitflag，但负流量不构成有效发动机工作点。

首次非设计点的同类公式重放：

```text
WA0+WA1 = -3.9612885102398579e-11
PW_REF = 8.2812161760728292e-11
平方根内的值 = -581.07196921710602
THRUST_REF = 2.3767731061439146e-12 - 9.5488580454887781e-13 i
```

原有`X=real(X)`之前和之后的变量均已保存。本次首次复数出现在派生结果字段，
没有证据表明这条已有语句是本次复数的来源；本阶段没有改动它。

## 原推力目标对照与扫描状态

只将推力恢复为`INPUT_TURBO`该分支的98 kN后：

| 字段 | 两侧一致的值 |
|---|---:|
| DP.WA | 331.48794077055169 kg/s |
| DP.THRUST | 97.999999999999972 kN |
| DP.PW_REF | 22063.487928507122 kW |
| DP.THRUST_REF | 102.67965794102584 kN，虚部0 |
| fsolve exitflag | 1 |
| 残差无穷范数 | 3.1283161661121995e-11 |

当前构型目录的设计条件节点默认`thrust=0、air_mass_flow=0`，原分支初始化的推力为98。
本次任务又将功率设为0，形成上述零目标组合。原`TURBOSHAFT_MAIN`同样可以覆盖原分支目标，
所以相同输入在原项目也复现异常。本次未自动改变已有工程或模板参数。

两侧零目标扫描均完成，但100个速度点和100个高度点全部返回`exitflag=0`，
消息为超过500次函数计算限制。速度阶段残差范围约为0.000469—0.007319，
高度阶段约为0.004229—0.007251。平台现有诊断因残差不超过0.001，将7个速度点
标记为converged；其余93个速度点和全部高度点为false。这个诊断判据本次未改动。
因此流程完成不能作为全扫描已收敛的结论。

## 后续处理建议

对本次分排涡扇的设计点，使用所需推力目标或明确的正空气流量，保留用户需要的轴功率设置；
PWG=0本身可以表示不对外发电，不必为消除复数随意增加发电负载。
98 kN是此次已验证的设计点对照，并不代表任意扫描工况都保证收敛。
是否调整构型目录的默认设计目标、增加负流量工作点提示或修改原求解策略，应另行确定；
本阶段没有为通过序列化而修改物理公式、截断虚部或自动改写用户输入。
